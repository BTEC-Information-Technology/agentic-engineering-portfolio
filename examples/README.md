# Examples

> **All content in this folder is sanitized or synthetic.** The examples are inspired by patterns from the production workflow, but no production code, no real identifiers, and no real data appear here. Each example is clearly labelled.

The purpose of these examples is to give a feel for the artifacts and conventions used on the real project, without exposing proprietary surface. They are reading material, not usable code.
